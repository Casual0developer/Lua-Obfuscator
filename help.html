How LuaVeil works

Scramble local names, encode constants, and condense the code while preserving its structure.

A local workspace for preparing and exporting your Lua source.
01

Names and layered constants

Local declarations and their references get matching randomized names. Strings, table keys, and property names use compact packed records in a shuffled pool. Each constant gets independent parameters for one to four reversible layers, including position mixing, byte feedback, modular arithmetic, and optional reversal.

The packing alphabet uses 64 randomized symbols drawn from printable ASCII characters 33–126. Encoded records are stored in delimiter-safe Lua long strings, allowing punctuation, quotes, and brackets without changing the program's syntax.

The decoder works in place and runs once per unique constant before the script starts. Repeated property access uses a table lookup; it does not rerun the layers. More layers add startup work. Empty constant pools generate no decoder. Method calls using : retain their call behavior.

The output uses string.byte, string.char, and table.concat from the target environment. The decoder and parameters are included, so the encoding is reversible.

02

Formatting and recovery

Valid Lua can always be formatted into multiple lines. Formatting does not restore discarded variable names or decode constants. Extra layers make the constant representation more involved, but code and keys delivered to a client can still be inspected and recovered. Sensitive credentials and authorization decisions need protection outside the distributed script.

03

Your supplied watermark comments

-- This script was generated using MoonVeil 2.1.1 [https://moonveil.cc]
--[[ v1.0.0 https://wearedevs.net/obfuscator ]]
--[[ obfuscated @ discord.gg/25ms ]]

These exact supplied comments are added once when enabled. No extra watermark names are generated. The line comment needs a newline so it does not comment out the program; the code body can still occupy a single long line.

04

Larger output and symbol padding

The junk-block slider selects 0–128 isolated calculations, with 32 selected by default. The junk toggle controls those blocks.

Symbol padding is a separate size control from 0–2048 KB, with 512 KB selected by default. It inserts random printable symbols and spaces inside an inert Lua long comment. Padding increases the file's visual bulk without adding runtime work or extra security. It remains independent of the junk-block toggle.

The output page reports padding size and the complete UTF-8 file size so you can see the size cost before downloading.

05

Local processing

Your Lua source is parsed as UTF-8 text and processed in a background worker. The browser does not run the supplied Lua code. Processing can be cancelled and stops after 15 seconds. Files are limited to 1 MB and generated output to 8 MB.

The input draft and latest output are saved in this tab's session storage when available. If storage is blocked or full, the output remains available on the editor page for copying or downloading.

06

Compatibility

Modes cover Lua 5.1–5.3, LuaJIT, and a subset of Roblox Luau. The Luau mode recognizes compound assignments, contextual continue, floor division, and binary or separated numeric literals. Strings and comments are kept outside these syntax workarounds.

Luau type annotations, interpolated strings, if expressions, and Lua 5.4 attributes are not supported.

The input and output are checked for active local variables and lexical capture limits. Unsupported or oversized output stops with an error instead of being offered as valid code. These targeted checks do not cover every compiler register limit or replace the official compiler.

Code that inspects local names or depends on debug information can observe the transformation. A shebang is retained for multiline output and removed when producing a single-line code body. A full Lua VM wrapper is not included. Test generated output in the target environment.

All processing stays in your browser. Start with a pasted script or a Lua file.
